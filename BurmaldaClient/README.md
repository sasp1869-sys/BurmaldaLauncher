# Burmalda Client

Initial Fabric client mod for Minecraft 1.21.1.

## Current features
- RGB-accent Burmalda HUD
- FPS and player coordinates display
- Open the Burmalda menu with Right Shift
- Toggle the HUD from the menu

## Build
The `Build Burmalda Fabric Client` GitHub Actions workflow builds the mod with Java 21 and uploads the JAR as the `BurmaldaClient-Fabric-1.21.1` artifact.

Install the resulting JAR into the `.minecraft/mods` folder alongside Fabric API.
